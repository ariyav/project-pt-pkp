Campus — Free Online Course / E-Learning Platform Template (uiCookies)

Concept
Campus dresses an e-learning marketplace in a "study hall" identity: a friendly-but-credible
look that borrows from real campuses — chalkboard greens, marigold highlights, and a graduation-cap
logo mark — instead of the generic purple SaaS gradient. The layout is built around a working
course-search hero and a filterable eight-card course grid, so the page feels like a product you
could actually enroll on. Warm floating rating/certificate chips, an animated stats band, a
three-step "how it works" with a dashed guide line, and a swipeable testimonials rail keep it lively
without shouting.

Palette ("Study Hall")
  #14342B  chalkboard pine    (headings, stats band, footer)
  #1E7A50  confident green     (primary buttons, links, accents)
  #F2A93B  marigold            (stars, badges, teach-with-us CTA)
  #E8674C  coral               (price / free tag accent, used sparingly)
  #F4F6F2  warm paper          (page background, faint green bias)
  #E2E8DE  soft line           (borders, dividers)

Font pairing
  Display: Bricolage Grotesque (600–800) — characterful, slightly quirky headings
  Body:    Mulish (400–800) — friendly, highly legible humanist sans

Tech
  Bootstrap 5 (self-hosted) + one custom CSS file + one vanilla-JS file. No jQuery, no CDN
  scripts, no icon fonts — every icon is inline SVG. Interactions (mobile nav, smooth scroll,
  course filter, count-up stats, scroll reveal, testimonials slider, form validation) are all
  hand-written and guard-claused. Respects prefers-reduced-motion. Free for personal and
  commercial use.
